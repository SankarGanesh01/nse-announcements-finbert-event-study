# Tables

This folder contains summary statistics and regression outputs from the event-study analysis.

| File | Description |
|---|---|
| `table1_sample_summary.csv` | Number of observations included for each company. |
| `table2_descriptive_statistics.csv` | Descriptive statistics for sentiment, CAR, and text features. |
| `table3_main_regression.txt` | Main OLS regression results for CAR(-1,+1). |
| `table4_robustness_results.csv` | Regression results across alternative event windows. |
| `regression_results.csv` | Summary of model sample sizes and R² values. |
